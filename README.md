# Vocab Deck

TOEIC向けオリジナル単語350語（レベル1〜7、各50語）の個人用練習サイトです。外部ライブラリやアカウント登録は不要です。

## できること

- 英語→日本語、日本語→英語の単語カード（入力不要）
- 最初の1文字ヒント、レベルごとの1〜10語・11〜20語などの10語セット
- わかる／あやふや／わからないの記録と苦手語の優先復習
- 10語の範囲を掲載順に学ぶ「順番に」と、選択レベルの50語から重複なく10語を出す「ランダム」
- IndexedDBへの回答ごとの保存、JSONバックアップの書き出し・読み込み
- 初回読み込み後のオフライン利用、ホーム画面への追加

## 公開

GitHub Pagesで公開する場合、リポジトリの Settings → Pages で `Deploy from a branch`、`main`、`/(root)` を選びます。全ファイルをリポジトリ直下に置いてください。サイトはHTTPSで開いてください。

## ローカル確認

`python3 -m http.server 8000` で起動し、`http://localhost:8000` を開きます。`file://` でHTMLを直接開くと単語データやオフライン機能が動きません。

## 単語データ

`words.tsv` が編集しやすい元データ、`words.json` がサイトで読み込むデータです。レベル・単語・日本語訳・オリジナル例文の順に並んでいます。追加時は単語ごとに一意のIDを維持してください。現在のレベルは公式のTOEICスコアに対応する区分ではありません。

学習記録はブラウザの保存領域にあります。ブラウザのデータを削除した場合に備え、設定画面からJSONを定期的に書き出してください。
